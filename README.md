# Pizza-Sales-Analysis-SQL-PowerBI
Analysis of pizza sales data using SQL and Power BI to identify sales trends, best-selling pizzas, revenue performance, and business insights through interactive dashboards.
## Dataset Description

The dataset contains pizza sales transactions,
including order details, pizza characteristics,
pricing information, and customer purchasing patterns.

| Column | Description |
|---|---|
| pizza_id | Unique identifier for each pizza record |
| order_id | Unique identifier for each order |
| pizza_name_id | Short identifier for the pizza type and size |
| quantity | Number of pizzas ordered |
| order_date | Date when the order was placed |
| order_time | Time when the order was placed |
| unit_price | Price per pizza |
| total_price | Total price for the ordered quantity |
| pizza_size | Size of the pizza |
| pizza_category | Category of the pizza |
| pizza_ingredients | Ingredients used in the pizza |
| pizza_name | Full name of the pizza |
